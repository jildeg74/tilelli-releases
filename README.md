# Tilelli — Amazigh encyclopedia for Android

**Tilelli** (« liberté » en tamazight) est une encyclopédie mobile du monde amazigh : histoire, personnalités, langue et alphabet tifinagh, culture, proverbes, calendrier et quiz. Gratuite, avec publicités.

*Tilelli (“freedom” in Tamazight) is a mobile encyclopedia of the Amazigh world: history, notable people, language and the Tifinagh alphabet, culture, proverbs, calendar and a quiz. Free, with ads.*

## Installer (Android) / Install

**Français**
1. Téléchargez le fichier `.apk` depuis la page « Releases » (depuis votre téléphone).
2. Ouvrez-le. Android vous demandera d'autoriser l'installation d'applications depuis ce navigateur (« Installer des applications inconnues ») : autorisez-le, puis revenez en arrière.
3. Touchez **Installer**. Selon votre version d'Android, Google Play Protect peut afficher un avertissement parce que l'application ne vient pas du Play Store : choisissez « Plus de détails », puis « Installer quand même ».
4. Vous pouvez retirer l'autorisation du navigateur ensuite, dans les paramètres.

**English**
1. Download the `.apk` file from the “Releases” page on your phone.
2. Open it. Android will ask you to allow installs from this browser (“Install unknown apps”): allow it, then go back.
3. Tap **Install**. Depending on your Android version, Google Play Protect may show a warning because the app is not from the Play Store: choose “More details”, then “Install anyway”.
4. You can remove the browser’s permission afterwards in Settings.

## Vérifier le fichier / Verify the file
Chaque version indique l'empreinte **SHA-256** du fichier dans ses notes. Sous Windows : `Get-FileHash Tilelli-x.y.z.apk -Algorithm SHA256`.
